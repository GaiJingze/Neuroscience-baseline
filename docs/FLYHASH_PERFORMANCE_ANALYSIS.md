## 🔬 为什么 FlyHash 聚类性能不是 SOTA？

### 这是**预期的**，原因如下：

1. **设计目标不同**
   - FlyHash 主要为 **检索/哈希**，不是聚类
   - 优化目标是 **保持近邻关系**，而非全局聚类结构

2. **无训练/无监督**
   - FlyHash 使用 **随机投影**，不从数据学习
   - 没有针对特定数据集优化

3. **极端稀疏性**
   - 只保留 5% 的激活（top-100 out of 2000）
   - 丢失了大量信息，换取速度和稀疏性

4. **聚类算法限制**
   - 使用简单的 K-Means
   - 没有利用 FlyHash 的哈希特性（更适合检索任务）
