# Clustering Evaluation Metrics Explained

## Overview

在聚类任务中，我们使用多个指标来评估聚类质量。最常用的两个指标是 **NMI** 和 **ARI**。

---

## NMI (Normalized Mutual Information)

### 定义
**标准化互信息** - 衡量聚类结果与真实标签之间的**信息一致性**

### 数学原理

NMI 基于信息论中的互信息（Mutual Information）：

```
MI(U, V) = ∑∑ P(u,v) log(P(u,v) / (P(u)P(v)))

NMI(U, V) = MI(U, V) / √(H(U) × H(V))
```

其中：
- `U` = 真实标签 (ground truth)
- `V` = 聚类结果 (predicted clusters)
- `H(U)`, `H(V)` = 熵 (entropy)
- `MI(U, V)` = 互信息

### 取值范围
- **0**: 聚类结果与真实标签完全独立（最差）
- **1**: 聚类结果与真实标签完全一致（完美）

### 解读

| NMI 值 | 质量评价 | 含义 |
|--------|---------|------|
| 0.8-1.0 | 优秀 | 聚类结果几乎完美匹配真实类别 |
| 0.6-0.8 | 良好 | 聚类捕获了大部分类别结构 |
| 0.4-0.6 | 中等 | 聚类部分反映了真实结构 |
| 0.2-0.4 | 较差 | 聚类与真实标签相关性较弱 |
| 0.0-0.2 | 很差 | 聚类基本上是随机的 |

### 优点
✅ **对称性**: NMI(U, V) = NMI(V, U)  
✅ **归一化**: 不受类别数量影响  
✅ **信息论基础**: 理论基础扎实  

### 示例（MNIST）
```python
# 如果 NMI = 0.58 (Krotov 结果)
# 解释：聚类结果与真实数字标签共享约 58% 的信息
# 意味着聚类成功捕获了数据的主要结构
```

## ARI (Adjusted Rand Index)

### 定义
**调整兰德指数** - 衡量聚类结果与真实标签之间的**配对一致性**，并校正了随机聚类的影响

### 数学原理

ARI 基于 Rand Index，但调整了随机情况：

```
RI = (TP + TN) / (TP + FP + FN + TN)

ARI = (RI - E[RI]) / (max(RI) - E[RI])
```

其中：
- **TP** (True Positive): 两个样本在同一真实类别，也在同一聚类簇
- **TN** (True Negative): 两个样本在不同真实类别，也在不同聚类簇
- **FP** (False Positive): 两个样本在不同真实类别，但在同一聚类簇
- **FN** (False Negative): 两个样本在同一真实类别，但在不同聚类簇
- **E[RI]**: 随机聚类的期望 Rand Index

### 取值范围
- **-1 到 0**: 聚类结果不如随机猜测
- **0**: 聚类结果相当于随机猜测
- **0 到 1**: 聚类结果优于随机猜测
- **1**: 聚类结果与真实标签完全一致（完美）

### 解读

| ARI 值 | 质量评价 | 含义 |
|--------|---------|------|
| 0.8-1.0 | 优秀 | 几乎所有样本对都被正确分组/分离 |
| 0.6-0.8 | 良好 | 大部分样本对的关系被正确识别 |
| 0.4-0.6 | 中等 | 显著优于随机聚类 |
| 0.2-0.4 | 较差 | 仅略优于随机聚类 |
| 0.0-0.2 | 很差 | 接近或不如随机猜测 |

### 优点
✅ **调整随机性**: 校正了偶然一致性  
✅ **平衡性**: 考虑了所有样本对  
✅ **直观性**: 基于配对的一致性  

### 示例（MNIST）
```python
# 如果 ARI = 0.47 (Krotov 结果)
# 解释：47% 的样本对被正确分组/分离（扣除随机因素后）
# 意味着聚类质量明显优于随机分配
```

---

## NMI vs ARI: 区别与联系

### 核心区别

| 维度 | NMI | ARI |
|-----|-----|-----|
| **理论基础** | 信息论（熵、互信息） | 组合数学（样本对一致性） |
| **衡量对象** | 标签分布的信息重叠 | 样本对的分组一致性 |
| **敏感性** | 对聚类数量敏感度低 | 对类别不平衡更敏感 |
| **解释性** | 信息共享程度 | 配对正确率（扣除随机） |

### 共同点
✅ 都是外部评估指标（需要真实标签）  
✅ 都经过归一化/调整  
✅ 都在 [0, 1] 范围内（ARI 可以为负但通常 ≥ 0）  
✅ 值越大表示聚类质量越好  

### 如何选择？

**都使用！** 它们从不同角度评估聚类质量：

- **NMI**: 侧重于整体信息结构的匹配
- **ARI**: 侧重于具体样本对关系的正确性

如果两者都高，说明聚类质量确实好；如果只有一个高，需要进一步分析。

## 实际案例分析

### 案例 1: Krotov 在 MNIST 上的表现

```
NMI = 0.5837
ARI = 0.4683
ACC = 0.6313
```

**分析**：
- **NMI = 0.58**: 聚类捕获了约 58% 的真实标签信息
  - 说明聚类簇的整体分布与真实数字类别较为一致
  - 每个簇内的样本确实倾向于属于相同数字

- **ARI = 0.47**: 校正随机性后，47% 的样本对关系正确
  - 意味着大约一半的"应该在一起"的样本确实被聚在一起
  - 大约一半的"应该分开"的样本确实被分开了

- **结论**: 这是一个**中等偏上**的聚类结果
  - 明显优于随机聚类（ARI >> 0）
  - 对于无监督方法来说，这是相当不错的表现

### 案例 2: SoftHebb 在 MNIST 上的表现

```
NMI = 0.1806
ARI = 0.0878
ACC = 0.2094
```

**分析**：
- **NMI = 0.18**: 只捕获了 18% 的真实标签信息
  - 聚类结果与真实标签的相关性很弱
  
- **ARI = 0.09**: 几乎接近随机聚类水平
  - 样本对的正确分组率非常低

- **结论**: 这是一个**较差**的聚类结果
  - 可能存在训练不充分或超参数不当的问题
  - 聚类簇的区分度很低

### 案例 3: FlyHash 在 MNIST 上的表现

```
NMI = 0.5494
ARI = 0.4089
ACC = 0.5748
```

**分析**：
- **NMI = 0.55**: 作为无训练的随机投影方法，表现相当好
- **ARI = 0.41**: 略低于 Krotov，但仍然是中等水平

- **结论**: 
  - 随机投影已经能捕获数据的主要结构
  - Krotov 的学习过程带来了约 6% 的 NMI 提升

## 其他常用指标

### ACC (Accuracy)
- **定义**: 最优匹配下的准确率
- **范围**: [0, 1]
- **计算**: 需要找到聚类簇到真实类别的最优映射（匈牙利算法）

### Purity（纯度）
- **定义**: 每个簇中最多数类别的占比
- **问题**: 不考虑簇的数量（极端情况：每个样本一个簇，purity=1）

### Silhouette Score（轮廓系数）
- **定义**: 内部评估指标，不需要真实标签
- **范围**: [-1, 1]
- **衡量**: 簇内紧密度 vs 簇间分离度

## 快速参考

### 判断聚类质量的经验法则

```
优秀聚类:   NMI > 0.7  AND  ARI > 0.6
良好聚类:   NMI > 0.5  AND  ARI > 0.4  ← Krotov 在这个区间
中等聚类:   NMI > 0.3  AND  ARI > 0.2
较差聚类:   NMI > 0.1  AND  ARI > 0.1  ← SoftHebb 在这个区间
很差聚类:   NMI ≈ 0   AND  ARI ≈ 0
```

### Python 计算示例

```python
from sklearn.metrics import normalized_mutual_info_score, adjusted_rand_score

# true_labels: 真实标签 [0, 1, 2, ..., 9]
# pred_labels: 聚类结果 [3, 1, 0, ..., 7]

nmi = normalized_mutual_info_score(true_labels, pred_labels)
ari = adjusted_rand_score(true_labels, pred_labels)

print(f"NMI: {nmi:.4f}")  # 0.5837
print(f"ARI: {ari:.4f}")  # 0.4683
```

## 总结

### NMI (Normalized Mutual Information)
🎯 **本质**: 聚类结果与真实标签共享多少信息  
📊 **范围**: [0, 1]，越大越好  
💡 **直观理解**: "如果我知道了聚类结果，我能推断出多少真实标签的信息？"

### ARI (Adjusted Rand Index)
🎯 **本质**: 校正随机性后，样本对的分组正确率  
📊 **范围**: [-1, 1]，通常 [0, 1]，越大越好  
💡 **直观理解**: "聚类是否把该在一起的放一起，该分开的分开？"

### 使用建议
1. **同时报告 NMI 和 ARI**：提供更全面的评估
2. **加上 ACC**：提供直观的准确率参考
3. **对比多个方法**：单个指标值没有绝对意义，需要对比
4. **考虑任务特点**：某些任务对信息保留更重要，某些对配对正确性更重要
